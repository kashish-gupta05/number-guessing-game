## 🎯 Number Guessing Game

A simple Python game where the computer randomly selects a number between 1 and 100.

### Features

- Random number generation
- User guesses the number
- Gives "Too low" or "Too high" hints
- Counts total attempts
- Shows a congratulation message when the number is guessed

### Technology Used

- Python
- Random module
- While loop
- If-elif-else conditions
